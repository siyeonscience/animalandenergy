# 카메라 연동 호흡 (breathing/camera)

전면 카메라로 **어깨**(1순위)와 **손**(2순위)을 인식해서, 기존 3D 호흡 모형을 움직여요. 입 모양은 쓰지 않아요.

| 순위 | 동작 | 3D 모형 |
|---|---|---|
| 1순위 어깨 | 기준보다 올리기 | 들숨 (가로막 내려감) |
| | 기준보다 내리기 | 날숨 (가로막 올라감) |
| 2순위 손 (상체 옆으로 손을 올리면 전환) | ✊ 주먹 (손바닥이 안 보임) | 가로막 내려감 (들숨) |
| | 🖐 손가락을 펴서 손바닥이 보임 | 가로막 올라감 (날숨) |
| | ✌ 브이·검지 등 손바닥이 가려짐, 손등이 보임 | **"인식할 수 없습니다."** (상태 그대로) |

- 손을 내리면(1초 동안 안 보이면) 다시 어깨로 돌아와요. 가슴 앞에 있는 손은 무시해요.
- 어깨도 손도 안 보이면 호흡 상태를 바꾸지 않고, 자동·수동 모드로 바꾸는 버튼을 보여 줘요.
- 영상과 인식 결과는 브라우저 안에서만 처리하고, 저장하거나 밖으로 보내지 않아요.
  MediaPipe 라이브러리 안의 사용 통계 전송도 `mediapipe.js`에서 막아 두었어요.

## 파일
| 파일 | 하는 일 |
|---|---|
| `config.js` | 모든 기준값(임계값, 유지 시간, 처리 빈도)과 **인식 상태 표시 켜기/끄기** |
| `stream.js` | 전면 카메라 열기/닫기, 카메라 오류 안내 문구 |
| `mediapipe.js` | Pose Landmarker(어깨)·Gesture Recognizer(손) 불러오기 (`vendor/mediapipe`, GPU → CPU 자동 전환) |
| `shoulders.js` | 어깨 11·12번만 사용, 2초 기준점, 지수 이동 평균, 히스테리시스, 거리 변화 시 기준 다시 재기 |
| `hand.js` | 상체 옆으로 올린 손 찾기, 주먹/손바닥/인식 불가 판단(제스처 + 손바닥 방향 + 펼친 손가락 수) |
| `fusion.js` | 1순위 어깨 / 2순위 손 결합 규칙 |
| `zoom.js` | 카메라 배율 0.5~1배: 기기 카메라 배율(지원할 때) → 나머지는 화면 배율, 선택값 기억 |
| `align.js` | 어깨 위치·너비로 3D 모형 위치·크기 맞추기 (거울 방향 일치) |
| `controller.js` | 시작/종료 버튼, 어깨 기준 측정, 분석 반복, 상태 표시, 오류 처리 |
| `camera.css` | 카메라 화면, 상태 표시, 안내 상자, "인식할 수 없습니다." 표시 |

기존 3D 모형·애니메이션(`anatomy.js`, `respiration.js`의 `applyBreath`, 자동·수동 모드)은 그대로 쓰고,
카메라는 `modes.js`의 `CameraMode` 목표값만 바꿔요.

## 카메라 배율 (0.5배 ~ 1배)
카메라 조작판의 **카메라 배율** 막대로 조절해요. 이 기기에 기억돼요.
- 기기 카메라가 배율 조절을 지원하고 1배보다 작게(더 넓게) 찍을 수 있으면 → **기기 카메라 배율**을 써요.
- 지원하지 않거나 1배까지만 되면 → 영상을 작게 보여 주는 **화면 배율**로 줄여요 (주변은 어둡게, 3D 모형도 같이 작아짐).
- 어떤 방식으로 적용됐는지는 막대 아래에 표시돼요.
- 카메라는 센서 전체가 보이도록 4:3 화면을 먼저 요청해요 (16:9로 받으면 위아래가 잘려 더 확대돼 보여요).

## 인식 상태 표시 숨기기
- 화면: 카메라 조작판의 **‘인식 정보 숨기기’** 버튼 (이 기기에 기억돼요)
- 처음부터 숨기려면: `config.js`에서 `showStatusPanel: false`
- 숫자(어깨 이동량, 손 제스처 점수)만 숨기려면: `showDebugNumbers: false`

## 태블릿에서 실행
카메라는 보안 주소(https)에서만 켜져요.
1. GitHub Pages 주소로 열기: `https://siyeonscience.github.io/animalandenergy/breathing.html`
2. **📷 카메라 연동** → **카메라 시작** → 카메라 권한 **허용**
3. 정면을 보고 상체가 화면에 나오게 서서 2초 동안 가만히 (어깨 기준 위치 측정)
4. 어깨를 올리고 내리며 확인 → 손을 상체 옆으로 올리고 주먹/손바닥으로 확인

처음 한 번은 인식 엔진과 모델(약 28MB)을 받느라 시간이 걸려요. 같은 Wi-Fi에서 `http://컴퓨터IP:8000`처럼
http 주소로 열면 브라우저가 카메라를 막아요.
