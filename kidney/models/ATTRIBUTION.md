# 3D 모델 출처 (urinary.glb)

`urinary.glb`는 아래 공개 해부학 데이터에서 콩팥(겉질·속질·콩팥깔때기), 콩팥동맥·정맥, 오줌관, 방광, 요도, 대동맥, 아래대정맥 부분만 골라 합치고 가볍게 줄인 모델입니다.

- **Z-Anatomy** — CC BY-SA 4.0 (https://www.z-anatomy.com)
- **BodyParts3D** © The Database Center for Life Science (DBCLS) — CC BY 4.0 (https://lifesciencedb.jp/bp3d/)
- **Human Reference Atlas 3D Reference Object: Kidney** (HuBMAP) — CC BY 4.0 (https://humanatlas.io)

변경 사항: 일부 부위만 선택, 메시 병합·단순화(gltf-transform, meshoptimizer), 색상 재지정.
이 파일(urinary.glb)은 CC BY-SA 4.0 조건에 따라 같은 라이선스로 배포됩니다.
